Morse Magic - The Swiss Army Knife for everything Morse Code!
(for fellow radio operators)

It can:
* Read CW Input from a Paddle
* Read and Decode Audio
* Send CW from a keyboard via BLE
* Fix your timing
* Connect to most virtual CW Bands
* Auto - transmit callsign/whatever you want

All of this, either standalone or connected to your device of choice!
It also has built in capacitive touch paddles, for backups/emergencies!
Controlled via built-in display and paddles or via bluetooth (html app required)

This is also my first PCB and first venture into designing electronics.
